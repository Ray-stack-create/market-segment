# Market Segmentation Analysis of McDonald's

This project provides an in-depth market segmentation analysis of McDonald’s customers using real-world survey data. It applies clustering techniques to uncover unique customer segments and understand behavioral patterns—providing actionable insights for personalized marketing strategies.

---

## 📄 Overview

The objective of this analysis is to:
- Identify distinct customer segments using clustering algorithms.
- Analyze demographic factors such as **age** and **gender**.
- Understand customer preferences and perceptions of McDonald's offerings.
- Help tailor McDonald's marketing efforts for each segment.

---

## 📁 Files Included

- `M_Donalds.ipynb` – Jupyter Notebook containing the full segmentation workflow in Python.
- `mcdonalds.csv` – Dataset with customer responses originally used in an R-based case study.

---

## 🔍 Key Features

- ✅ Implementation of clustering algorithms like **K-means** and **DBSCAN**.
- ✅ Segmentation based on multiple product perception features (e.g., *tasty*, *cheap*, *healthy*).
- ✅ Analysis of key demographics: **age** and **gender**.
- ✅ Clear visualizations (bar charts, component plots) to interpret clusters.
- ✅ Real-world insights applicable to marketing and business strategy in the **fast food industry**.
